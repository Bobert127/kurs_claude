# Profil LinkedIn — gotowe teksty do przeklejenia

> Kolejność wklejania: **1. Open to work → 2. Nagłówek → 3. About → 4. Skills**

---

## 1. „Open to work" — stanowiska

Wpisz kilka wariantów (LinkedIn dopasowuje oferty po tytułach — im więcej trafnych synonimów, tym lepiej).

**Po polsku:**
- Specjalista ds. systemów HR / HRIS
- Konsultant TETA HR
- Analityk danych HR
- Lider zespołu ds. zarządzania danymi
- Specjalista ds. raportowania i analizy danych
- Administrator systemu kadrowo-płacowego
- Specjalista ds. wsparcia aplikacji HR

**Po angielsku:**
- HRIS Specialist
- HR Systems Consultant
- HR Data Analyst
- Data Management Lead / Specialist
- Reporting & Data Analyst
- HR Application Support Specialist

**Ustawienia pola:**
- Typ zatrudnienia: zaznacz wszystkie realne (pełny etat / kontrakt / B2B).
- Lokalizacje: Twoje miasto **oraz** „Praca zdalna" / „Remote".
- Widoczność: „Wszyscy użytkownicy LinkedIn" (ramka #OpenToWork) jeśli aktywnie szukasz; „Tylko rekruterzy" jeśli obecny pracodawca nie ma wiedzieć.

## 5. Audyt profilu — lista kontrolna (przejdź profil z góry na dół)

### Zdjęcie i tło
- [ ] Zdjęcie profilowe — twarz, jasne tło, profesjonalny wygląd
- [ ] Baner w tle z hasłem/obszarem (np. „TETA HR • Zarządzanie danymi • SQL & raportowanie")

### Nagłówek (Headline)
- [ ] Zawiera konkretne słowa kluczowe (TETA, SQL, raportowanie), nie samo „Specjalista"
- [ ] Rola + technologia + gotowość (wersja z sekcji 2)

### Custom URL
- [ ] Adres to linkedin.com/in/imie-nazwisko, nie ciąg cyfr (Edytuj publiczny adres URL)

### About / Informacje
- [ ] W 1. osobie, zaczyna od wartości („Pomagam…"), nie od CV-historii
- [ ] Słowa kluczowe spójne z nagłówkiem i Skills
- [ ] Wersja EN dodana pod PL

### Doświadczenie
- [ ] Każde stanowisko z opisem efektów (co usprawniłeś, skala: użytkownicy/dane/raporty)
- [ ] 3–5 umiejętności przypisanych do każdego wpisu
- [ ] Słowa kluczowe branżowe widoczne
- Wzór punktu: „Zbudowałem raporty SQL/GenRap dla ewidencji czasu pracy dla ~X pracowników; skróciłem czas przygotowania zestawień z Y do Z."

### Umiejętności (Skills)
- [ ] Top 3 przypięte (SQL, TETA HR, HR Analytics)
- [ ] Lista celna (15–25 trafnych), bez przypadkowych tagów
- [ ] Umiejętności powiązane ze stanowiskami
- [ ] Endorsements zebrane przynajmniej dla Top 3

### Certyfikaty / Licencje
- [ ] Dodane szkolenia: TETA, SQL/Oracle, Excel/Power BI, kursy HR/czas pracy (nawet producenckie/wewnętrzne, z datą)

### Języki
- [ ] Polski (ojczysty) + angielski z poziomem

### Open to work
- [ ] Aktywne, lokalizacja zdalna + wszystkie realne typy zatrudnienia
- [ ] Wpisane stanowiska (lista z sekcji 1)
- [ ] Widoczność ustawiona świadomie (#OpenToWork vs. tylko rekruterzy)

### Wiarygodność (opcjonalnie, podbija zasięg)
- [ ] Kilka rekomendacji (Recommendations)
- [ ] Minimalna aktywność w tematach TETA/HR/dane
- [ ] Wykształcenie uzupełnione

## Priorytety — od czego zacząć (największy efekt najmniejszym nakładem)

1. Nagłówek + About (PL/EN) — najszybciej podnosi trafialność w wyszukiwarce
2. Open to work ze stanowiskami i lokalizacją zdalną
3. Top 3 Skills przypięte + endorsements
4. Opisy stanowisk z efektami
5. Reszta (certyfikaty, języki, URL, baner)
